# Elderly Care Frontend

This is the React + Vite frontend for the Elderly Care Platform, built with a strong focus on accessibility.

## Setup
1. `npm install`
2. Create a `.env` file based on `.env.example`.
3. Run `npm run dev` to start the development server.

## Environment Variables
- `VITE_API_URL=http://localhost:5000/api`
- `VITE_SOCKET_URL=http://localhost:5000`

## Roles
- **Elderly User**: Simplified UI, huge tap targets, high contrast, SOS button.
- **Guardian**: Real-time alerts, activity timeline oversight.
- **Caregiver**: Credibility score dashboard and knowledge base management.
- **Admin**: System-wide oversight.
